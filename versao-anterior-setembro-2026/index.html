COMO UTILIZAR

Sobre a central

Este site é estático e pode ser hospedado no GitHub Pages. A base inicial de setembro de 2026 está incluída no pacote.

Ao importar um .xlsx, os valores disponíveis de todas as abas são carregados e podem ser escolhidos no seletor; fórmulas, imagens, formatação e macros não são preservadas. Arquivos .csv têm somente uma aba lógica.

O painel faz os cálculos localmente. Nada é enviado a um servidor pelo site. Alterações importadas permanecem nesta sessão, até que você use a opção de armazenamento local.

A data e a hora são atualizadas a cada segundo pelo relógio do dispositivo, no fuso de São Paulo (não são obtidas de um servidor de horário). Não há sincronização com sistemas da Enel ou com o SharePoint.
